1.Retrofit2 接口定义机制

定义一个 interface（接口），Retrofit 会在运行期间动态地帮你把这个接口“翻译”成真正的网络请求代码。

2.OkHttp3 拦截器机制

用于统一添加公共参数。例如每个新闻请求都需要带上 key=d28aec02329d46150613b932b660dd9b，

可以用拦截器在最上游统一拦截并拼接，不需要在每个接口里手动传 KEY。

3.ViewBinding使用

Activity 初始化，通过 ActivityMainBinding.inflate(getLayoutInflater()) ，并使用 setContentView(binding.getRoot()) 挂载

ViewBinding的优势，即空安全，直接引用生成的变量，不会访问当前布局没有的 ID，杜绝了 NullPointerException 导致的闪退。

4.JSON 解析库

implementation("com.squareup.retrofit2:converter-gson:2.9.0")


Gson等解析库通过 Java 反射机制，自动将 JSON 中的 Key 与 Java 类中的属性名进行强行对齐和数据转换，完成自动解析。
