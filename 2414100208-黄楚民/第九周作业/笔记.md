# 第九周学习笔记 — 数据持久化 Room 数据库

## 核心知识点

### 1. ORM 映射思想
- ORM（Object-Relational Mapping）将数据库表映射为 Java 对象
- Room 是 Android 官方的 ORM 框架，基于 SQLite，编译时检查 SQL 语句
- 三大核心组件：Entity（表）、DAO（数据访问对象）、Database（数据库）

### 2. Entity 定义
- 使用 `@Entity` 注解标记类为数据库表
- `@PrimaryKey(autoGenerate = true)` 自动生成主键
- 类的字段对应表的列

```java
@Entity(tableName = "favorites")
public class FavoriteArticle {
    @PrimaryKey(autoGenerate = true)
    public int id;
    public String title;
    public String author;
}
```

### 3. DAO 接口
- 使用 `@Dao` 注解标记接口
- `@Insert`、`@Delete`、`@Query` 注解定义数据库操作
- 返回 `LiveData<List<T>>` 可实现数据自动刷新

```java
@Dao
public interface FavoriteDao {
    @Insert
    void insert(FavoriteArticle article);

    @Query("SELECT * FROM favorites ORDER BY timestamp DESC")
    LiveData<List<FavoriteArticle>> getAll();
}
```

### 4. Database 单例
- 使用 `@Database` 注解，声明 entities 和 version
- 通过 `Room.databaseBuilder()` 创建实例
- 使用单例模式避免重复创建数据库连接

### 5. Room 与 LiveData 结合
- DAO 方法返回 `LiveData` 时，数据变化会自动通知观察者
- 无需手动刷新 UI，插入/删除后列表自动更新

## 踩坑记录

### 坑1：主线程操作数据库崩溃
- 原因：Room 默认不允许在主线程执行数据库操作
- 解决：使用 `Executors.newSingleThreadExecutor().execute()` 在子线程操作

### 坑2：annotationProcessor 配置
- 原因：Room 需要编译时注解处理器生成代码
- 解决：在 build.gradle 中添加 `annotationProcessor("androidx.room:room-compiler:2.6.1")`

## 关键代码片段

```java
// 切换收藏状态
public void toggleFavorite(News.Article article) {
    Executors.newSingleThreadExecutor().execute(() -> {
        FavoriteArticle existing = favoriteDao.findByTitle(article.title);
        if (existing != null) {
            favoriteDao.delete(existing);
        } else {
            favoriteDao.insert(new FavoriteArticle(
                article.title, article.author_name,
                article.date, System.currentTimeMillis()));
        }
    });
}

// Activity 中观察收藏列表（自动刷新）
```
